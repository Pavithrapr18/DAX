Power BI Assignment 2 - DAX & Data Visualization

E-Commerce Sales Analysis

Files to use:
- List of Orders.csv
- Order Details.csv
- Sales target.csv
- 
Complete data modeling before visualization.
Create the required relationships between tables and derive the necessary calculations.
Format visuals clearly.

Calculated Columns

1. Create Category Type in Order Details by combining Category and Sub-Category.
2. Create a revenue column in Order Details: Amount * Quantity.
3. Create Sales Category in Order Details, labeling each order as Above Average or Below Average based on its Amount.

Calculated Measures

1. Calculate total order count in Order Details.
2. Calculate average profit for orders placed in Delhi.
3. Calculate Year-to-Date sales from the earliest order date through each order date.

Required Visualizations

1. Clustered column chart: actual sales vs. sales target by category.
2. Donut chart: maximum profit margin by sub-category.
3. Line chart: monthly sales trend.
4. Scatter chart: profit vs. quantity by sub-category.
5. Cards: total sales amount and sales target.
6. Multi-row card: minimum target for each segment.
7. Matrix: actual sales vs. targets by category and month.
8. Map: total sales by city.
9. Treemap: sales distribution by sub-category.
10. Funnel chart: order count by state.
